# 🏨 StayVista – Full Stack Web Application

StayVista is a modern **full-stack hotel booking web application** that allows users to explore stays and hosts to manage property listings.  
Built using **Node.js, Express, MongoDB, and EJS**, this project follows **MVC architecture** and focuses on clean UI and scalable backend design.

---

🔗 **Live Demo:** https://stayvista-airbnbclone-1.onrender.com/

## 🚀 Live Features

### 👤 User Side
- 🔐 User Authentication (Register / Login)
- 🏨 Browse hotel & stay listings
- 📄 View detailed stay pages
- 📱 Fully responsive design
- ⭐ Reviews & Ratings System

### 🛠️ Host / Admin Side
- ➕ Create new stay listings
- ✏️ Update existing listings
- ❌ Delete listings
- 🖼️ Upload & manage images

## ⚙️ Installation & Setup

1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/StayVista.git
```

2️⃣ Move into the project folder
```bash
cd StayVista
```

3️⃣ Install dependencies
```bash
npm install
```

4️⃣ Start the development server
```bash
nodemon app.js
```

5️⃣ Open in your browser
```
http://localhost:3000
```
